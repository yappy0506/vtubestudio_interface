## 1. 接続/認証デモ

1. vtsからブロードキャストされている情報を取得し、コンソールに出力する。
2. 取得した情報をもとにvtsに接続する。
3. トークンを持っていないものとして、認証を要求する。
4. vtsから承認を受けるまで待機する。(タイムアウト30秒)
5. 何らかのAPIを実行し、成否を確認する。
6. 一度vtsdを終了する。
7. vtsdを再起動し、vtsに再接続する。
8. 4で取得したトークンを利用し、認証を要求する。
9. 認証の成否をコンソールに出力する。

## 2. キャラクターロードデモ

1. vtsに接続する。
2. トークンを持っていないものとして、認証を要求する。
3. vtsから承認を受けるまで待機する。(タイムアウト30秒)
4. 使用可能なキャラクターの一覧を取得し、コンソールに出力する。
5. リストのキャラクターを5秒ごとに一人一人ロードとアンロードする。

## 3. HotKey実行デモ

1. vtsに接続する。
2. トークンを持っていないものとして、認証を要求する。
3. vtsから承認を受けるまで待機する。(タイムアウト30秒)
4. (キャラクターがロードされていなかった場合)キャラクター"Akari"をロードする。
5. HotKeyのリストを取得し、コンソールに出力する。
6. リストのホットキーを5秒ごとにすべてを実行する。

## 4. キャラクター移動デモ

1. vtsに接続する。
2. トークンを持っていないものとして、認証を要求する。
3. vtsから承認を受けるまで待機する。(タイムアウト30秒)
4. (キャラクターがロードされていなかった場合)キャラクター"Akari"をロードする。
5. キャラクターを画面の四隅に移動させた後、中心に戻す。
6. キャラクターサイズを最小から最大まで変化させ、デフォルトのサイズに戻す。
7. キャラクターをぐるっと回転させる。
